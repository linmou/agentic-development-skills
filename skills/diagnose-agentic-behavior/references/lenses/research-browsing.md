# Research and Browsing Lens

**Intent:** Coverage prompts for information-seeking tasks: web browsing, retrieval, research reports, and question answering.

| Prompt | Coverage question |
| --- | --- |
| Information need | Is there a type for what must be found, including precision and recency requirements? |
| Query plan | Can the search strategy be distinguished from the searches actually run? |
| Source set | Are retrieved sources typed with locator (URL plus retrieval time) and rendering method? |
| Source quality | Can selection or rejection of sources be expressed? |
| Extracted claim | Is a claim distinct from the source text it came from? |
| Claim–source binding | Can the link between a claim and its exact supporting span be checked and fail independently? |
| Synthesis | Can combination, aggregation, or arithmetic over claims be expressed separately from extraction? |
| Coverage of the need | Is there completion evidence that the need was answered, not merely that sources were cited? |
| Environment-state drift | Can a source that changed between retrieval and evaluation be expressed? |
